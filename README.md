# iptv-guide
Nightly XMLTV guide for the IPTV viewer app, built with [iptv-org/epg](https://github.com/iptv-org/epg).
Covers US channels, Israeli channels and English-language sports channels that appear in the iptv-org playlists.

Guide URL (after the first run): `https://raw.githubusercontent.com/<owner>/iptv-guide/guide/guide.xml.gz`
